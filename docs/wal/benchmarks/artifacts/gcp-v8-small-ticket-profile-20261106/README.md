# GCP V8 small-ticket profiling capture

This is a diagnostic-only capture from the retained GCP Free Trial C4 environment. It is not an RFC 026 performance qualification: all benchmark cells were instrumented, so their throughput and latency are attribution data only.

See [report.md](report.md) for environment, workload coverage, results, and caveats. The report and `summary.tsv`, `matrix-validation.json`, and `perf-self-symbols.txt` retain the useful findings; raw per-cell and perf capture archives are not included. No SSH credentials or reconnect keys are included.
