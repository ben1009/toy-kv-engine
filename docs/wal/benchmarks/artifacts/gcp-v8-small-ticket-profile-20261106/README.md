# GCP V8 small-ticket profiling capture

This is a diagnostic-only capture from the retained GCP Free Trial C4 environment. It is not an RFC 026 performance qualification: all benchmark cells were instrumented, so their throughput and latency are attribution data only.

See [report.md](report.md) for environment, workload coverage, results, and caveats. `profile-54c1a739.tar.gz` contains all per-cell raw outputs and perf data; the smaller summary files are split out for convenient review. No SSH credentials or reconnect keys are included.
